Copias Homelab

Sistema privado de copias de seguridad para servidores y aplicaciones.

Finalidad

Copias Homelab utiliza rclone y la API de Google Drive para almacenar y recuperar copias de seguridad en la cuenta de Google Drive autorizada por su administrador.

Uso de Google Drive

La conexión se autoriza mediante Google OAuth. Los permisos solicitados se destinan exclusivamente a gestionar los archivos de las copias de seguridad. La aplicación no solicita la contraseña de Google.

Acceso

Es una herramienta de uso privado, sin registro público. Esta web ofrece información sobre la aplicación y no permite acceder a las copias ni al servidor.
